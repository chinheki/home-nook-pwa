# 归处 · 全屋收纳
本地优先 PWA，无运行时依赖。浏览器 IndexedDB 存储照片、物品、平面图及购物车。

## 使用
首页编辑平面图：拖动移动，右下角缩放；点击柜子可编辑精确尺寸。点击“收一件”添加图片与物品；搜索支持名称、细分类、备注与位置。“清空”将数量标为零，可撤销；购物清单勾选后自动补货一件。

照片最长边 480px，以 25% WebP 画质压缩，浏览器不支持时使用 JPEG。13 个大类、超过 70 个小类。设置中可导出/导入完整 JSON 备份。

## 本地运行与检查
`python3 -m http.server 4173 --directory dist`

`npm test`

数据不跨设备同步。清除站点数据会清除本地记录，建议定期导出备份。PWA 的离线能力需要首次联网缓存成功。iPhone 安装与跨日存储仍需真机检查。
