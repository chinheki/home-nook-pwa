# 归处 · 全屋收纳
本地优先 PWA，无运行时依赖。浏览器 IndexedDB 存储照片、物品、平面图及购物车。

## 使用
首页编辑平面图：拖动移动，右下角缩放；点击柜子可编辑精确尺寸。点击“收一件”添加图片与物品；搜索支持名称、细分类、备注与位置。“清空”将数量标为零，可撤销；购物清单勾选后自动补货一件。

照片最长边 480px，以 25% WebP 画质压缩，浏览器不支持时使用 JPEG。13 个大类、超过 70 个小类。设置中可导出/导入完整 JSON 备份。

## 本地运行与检查
`python3 -m http.server 4173 --directory dist`

`npm test`

数据不跨设备同步。清除站点数据会清除本地记录，建议定期导出备份。PWA 的离线能力需要首次联网缓存成功。iPhone 安装与跨日存储仍需真机检查。

## 多房间与手机布局
手机竖屏优先，所有房间在同一张平面图显示。点击“编辑 → + 房间”添加房间；拖房间名移动、拖右下角缩放，柜子随房间一起移动。添加或编辑柜子时可选择所属房间，搜索与物品位置包含房间名。

旧版数据自动迁入“原有空间”，保留柜子 ID、原布局、照片、物品与购物清单；可先缩小原有空间，再添加其他房间。旧备份也可导入。

## 无名称收纳与详情页
柜子与收纳箱不需要命名；平面图只显示色块、边线与加号。四边实线表示有门或有盖；可选择上、右、下、左任意一边隐藏边线，表示半开放。点击加号进入独立收纳详情页，在当前收纳内添加、搜索、编辑物品。

编辑模式可拖动色块移动、拖右下角缩放，点击小铅笔设置颜色、所属房间与开放边。详情页也有编辑入口。位置自动显示房间与收纳序号，物品卡片的色点与图上色块对应。

旧版备份与数据自动升级到 v3，柜子 ID、房间关联、坐标、物品、照片及购物清单保留。
