# 归处 · 全屋收纳
本地优先 PWA。照片、物品、平面图与购物清单保存在当前浏览器的 IndexedDB，不上传服务器。

## 首页
首页为固定满屏平面图，不能上下滚动。所有房间显示在同一张图上；按钮浮在图上。底部依次为物品搜索、随机零食、新增物品、购物清单，各列表放在独立页面。

点铅笔进入编辑模式，可添加房间或收纳。房间只填名称和颜色，拖动房间名移动、拖右下角缩放。柜子无需名称，选择所属房间、颜色与开放边；拖动色块移动，拖右下角缩放。

四边实线表示有门／有盖；可选择上、右、下、左其中一边不画线，表示半开放。点色块上的加号进入收纳详情，在该收纳内添加、搜索和编辑物品。

## 物品与补货
预设 13 大类、80 小类；物品最终选择小类。照片最长边 480px、WebP 25% 画质，不支持 WebP 时使用 JPEG。

物品搜索支持名称、分类、备注和位置。“清空”标记用完，可撤销。“加入购物车”记入购物清单；勾选买到后补回一件库存。随机零食仅从有库存的零食中选择。

## 备份与安装
浮动设置按钮可导出或导入完整 JSON 备份。旧数据升级保留柜子 ID、房间、坐标、照片、物品和购物清单。初始旧布局放进“原有空间”。换设备或清除浏览器前请先导出备份。

浏览器菜单中选择安装应用／添加到主屏幕。首次联网缓存后可使用离线资源。真实手机安装、触摸与跨日存储仍需实机验证。

## 本地运行
`python3 -m http.server 4173 --directory .`

应用无运行时依赖。自动检查与浏览器验收记录保存在开发工作区。
