# 归处 · 全屋收纳 PWA

本地优先、面向手机的全屋收纳应用。[打开网页](https://chinheki.github.io/home-nook-pwa/)。

## 使用

- 首页为固定满屏平面图。右上角铅笔进入编辑，单指拖动柜子、双指调整大小；移动与缩放按网格变化，重叠会被阻止。房间名称可拖动，房间右下角可按网格缩放。
- 「更多 → 网格设置」选择粗 8×6、标准 12×9、细 16×12，统一对齐房间内部的柜子和柜体分格。放不下时保留原布局，不自动删减或缩小内容。
- 点柜子进入立面，再点格子查看物品。立面编辑支持双指缩放、复制空布局、跨柜移动、格子转独立柜子，以及预设三层、抽屉、衣柜。鼠标用户可在尺寸面板按格数设置，方向键移动，Shift + 方向键缩放。
- 移动操作先选房间与目标柜子，再拖动半透明预览或点空位，最后确认。盒内分组与物品一起移动。转柜子也保留分组、照片和物品。
- 柜子设置中的「复制空布局」复制全部结构，格子复制也保留盒内分组；两者都不复制物品。没有空位时会提示先腾出空间。
- 进入格子后是纯列表。Group 可展开/收起，组内直接显示物品；物品左滑出现清空/删除，点击进入详情页；右下角悬浮加号向当前格子添加物品。Group 菜单支持新增物品、重命名和删除空组，无需编辑盒内平面图。
- 物品支持数量（默认 1）、单位（默认件）和可选 Tag（逗号分隔，最多 12 个、每个最多 24 字）。搜索包含名称、种类、备注、房间、柜子、格子、分组名和 Tag。
- 物品表单分三页，左右三角翻页保留输入，最后一页固定按钮保存。更多菜单提供全部物品、随机零食、购物清单和备份。
- 编辑中的撤销/重做保留最近 20 次修改，限当前打开会话。替换布局模板时，原盒内分组会展开到新格子，物品保留，可撤销。
- 照片本机压缩至最长边 480px、WebP 25%（不支持时 JPEG），不上传服务器。首次联网后可离线打开，浏览器菜单可添加到主屏幕。

- 柜子页面和格子列表顶部可添加整体照片；点击照片可更换或移除。照片本机压缩、刷新保留，并包含在完整备份中。移动和转柜子保留照片；复制空布局不复制整体照片。替换分格模板会移除原格子的照片和 Group，操作前提示并可撤销。

## 数据与升级

IndexedDB 数据库仍为 `home-nook`。格式 v5 自动迁移 v1–v4，保留物品 ID、照片、数量、购物清单和已有几何布局；新字段补默认值。迁移不会强行重排原布局，选择网格后才统一对齐。删除含物品的柜子、格子或分组会被阻止；移动或转柜子后，原柜子可以留空。

换设备或清除浏览器前，在「更多 → 备份与设置」导出完整 JSON，导入覆盖前会确认。备份保留盒内分组、Tag 和单位。所有数据只在当前浏览器，各设备独立。

「备份与设置 → 检查更新」会联网核对版本。有新版本时提供重新载入按钮，请先保存正在编辑的内容。

## 维护

完整静态网站，无构建或运行时依赖。`npm test` 运行模型、数据迁移和布局操作测试。分类 SVG 来自 Lucide，源文件在 `icons/`，许可证见 `ICONS-LICENSE.txt`。图标统一描边并使用 `currentColor`。

GitHub Pages 由 `.github/workflows/pages.yml` 在 main 推送后自动测试、发布。部署目录仅复制公开静态文件。资源版本 `outdoor4`，离线缓存 `home-nook-v11`。

自动测试不能代替真实设备验证；实体 iPhone 双指操作、相机和跨天存储保持需要设备实测。
