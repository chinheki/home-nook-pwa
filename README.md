# 归处 · 全屋收纳 PWA

本地优先、面向手机的全屋收纳应用。发布入口：https://chinheki.github.io/home-nook-pwa/

## 使用

- 首页为固定满屏的抽象平面图，底部常驻搜索和添加按钮。
- 右上角铅笔进入编辑：拖动房间名称移动房间，拖右下角缩放。收纳拖动后自动贴墙，避开其他收纳。
- 点击彩色收纳进入柜体立面，点击格子查看物品。
- 立面编辑可移动、缩放、增删空格子；预设三层、抽屉、衣柜。替换预设会重新分配物品到新格子，不删除物品。
- 柜子与格子各自支持颜色、线条图标、可选名称和开放边。色盘在当前面板向下展开。
- 更多菜单中提供全部物品、随机零食、购物清单和备份。
- 搜索支持品名、种类、备注、房间、收纳名称及格子名称；结果显示位置，可清空数量、撤销和加入购物清单。
- 照片在本机压缩至最长边 480px、WebP 25%（不支持时 JPEG），不上传服务器。
- 浏览器菜单可添加至主屏幕。首次联网后支持离线打开。

## 数据

IndexedDB 数据库仍为 `home-nook`。数据格式 v4 自动迁移 v1–v3，保留物品 ID、图片、数量、购物清单及原平面布局；旧物品放入原柜子的第一格。已有平面布局不会被示例布局覆盖。删除有物品的柜子或格子会被阻止。

换设备或清除浏览器前，在「更多 → 备份与设置」导出 JSON；导入覆盖前会确认。

## 维护

仓库根目录是完整静态网站，不依赖构建。`npm test` 运行模型和迁移测试。SVG 分类图标源文件位于 `icons/`；应用内联相同图形以保证离线可用，来源 Lucide，许可证位于 `ICONS-LICENSE.txt`。图标使用 `currentColor`，便签自动派生同色系的深色图标；折角通过同色混合生成。

GitHub Pages 由 `.github/workflows/pages.yml` 发布。当前资源版本 `sticky1`，离线缓存 `home-nook-v7`。
